# 💳 Fraud Detection using Machine Learning

This project analyzes financial transaction data to detect fraudulent transactions using machine learning models.  
The dataset in `data/` contains small sample `.pkl` files as placeholders. Replace them with the full dataset for production.

## 📂 Project Structure
```
├── data/
│   ├── 2018-04-01.pkl
│   ├── 2018-04-02.pkl
│   └── 2018-04-03.pkl        ← sample placeholders
├── fraud_detection.ipynb     # Main notebook/script
├── README.md                 # Project documentation
├── fraud_detection.yaml      # Project configuration
├── requirements.txt
└── .gitignore
```

## Quickstart
1. Clone the repo and install dependencies:
```bash
pip install -r requirements.txt
```
2. Open `fraud_detection.ipynb` in Jupyter or Colab and run the cells.  
3. To use the full dataset, place your `.pkl` files in the `data/` folder and rerun.
